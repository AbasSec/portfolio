# AbasSec CTF Portfolio

## Open locally
Open `index.html` in a browser.

## What was improved
- Added a premium hero section with a built-in cyber / hacking themed background image.
- Kept the self-photo placeholder and made it more prominent.
- Added a more polished layout, glass-style panels, hover effects, and reveal animations.
- Kept the animated desktop cursor.

## Replace the profile photo
1. Put your image in `assets/`, for example `assets/abas-profile.jpg`.
2. In `index.html`, find:
   `src="assets/profile-placeholder.svg"`
3. Change it to:
   `src="assets/abas-profile.jpg"`

A portrait image in a 4:5 or 3:4 ratio works best.

## Hero background image
The hero background image is included as:
`assets/hero-ctf-bg.png`

If you want, you can replace it with another image and keep the same file name.

## Before publishing
- Replace the CTFtime placeholder link with your real CTFtime profile.
- Check that the CTF counts (18+, 120+, and 02) are accurate.
- Add writeups, rankings, or competition results when ready.

## Cursor effect
The portfolio includes an animated desktop cursor with a subtle trailing ring. It changes to green and expands over links and buttons, then compresses on click. It is automatically disabled on touch devices and for visitors who request reduced motion.
